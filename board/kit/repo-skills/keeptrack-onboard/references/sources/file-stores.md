# Google Drive, Dropbox, OneDrive

Client folders and files. Value: high for files. Follow `../folders.md`: link, do not move.

**Read it:** the Drive, Dropbox or OneDrive connector. List folders only (names, ids, last change). Do not read file contents unless the person asks a question about one.

**Find each client's folder:** search for folders with the client name (and short forms: "Northwind Ltd", "Northwind", "NW"). Prefer the top folder that holds most of that client's files. Show the match per client and ask about any doubt.

**The link:** Drive `https://drive.google.com/drive/folders/<id>`; Dropbox: a shared link or the web path the connector gives; OneDrive or SharePoint: the folder's web URL.

**Traps:** shared drives vs My Drive; "Shared with me" folders the person does not own (link them, but say so); one client folder per year.
