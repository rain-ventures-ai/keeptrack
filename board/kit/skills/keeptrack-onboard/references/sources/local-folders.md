# Local folders (on the person's computer)

Client folders on a Mac or PC. Value: high for files.

**Read it:** Cowork folder access (the person adds the folder), or Claude Code / Codex running on that computer. List names and dates only.

**The link:** if the folder is inside a synced Drive, Dropbox or OneDrive folder, use the web link of the same folder (everyone can open it). Otherwise use the absolute path (`/Users/chris/Work/Clients/Northwind`); the board shows it, but only agents on that computer can open it. Never `~/`.

**Traps:** Desktop and Downloads full of client files with no folder: list them in `inventory.md` and offer the template and a tidy-up; do not move them by default.
