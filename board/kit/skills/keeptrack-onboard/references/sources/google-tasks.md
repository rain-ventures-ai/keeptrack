# Google Tasks

Tasks and due dates. Value: medium. There is no Claude connector for Google Tasks yet.

**Read it:** Google Takeout (takeout.google.com > select only Tasks > export). The download has `Tasks.json`. As the last choice, read tasks.google.com in the browser.

**Map it:** each task list can be a client or a label (ask); `status: needsAction` only; `due` to `due`; sub-tasks to `todos`.

**Traps:** Takeout can take minutes to hours: start it early in the interview, and do the rest while it runs.
