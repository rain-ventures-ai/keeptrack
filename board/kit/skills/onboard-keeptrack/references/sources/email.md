# Email (Gmail, Outlook)

Who the real clients are, and the last contact. Value: high, but large. Follow `../finding-clients.md`.

**Read it:**
- Gmail: the Gmail connector (search with `in:sent after:YYYY/MM/DD`, read headers only).
- Outlook / Microsoft 365: a Microsoft connector if one is connected. If not, ask the person to export contacts (People > Manage > Export contacts) and use the browser only as the last choice.
- A person who will not connect email: skip. The named clients are enough.

**Never:** store message text, read attachments, or open a personal label without a yes. Never send or draft an email during onboarding.

**Traps:** shared mailboxes (info@) inflate counts; mailing lists look like people; one person with two addresses.
