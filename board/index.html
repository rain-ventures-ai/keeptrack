Help

A one-minute tour of Today, Kanban, People and the menus.

Today

One place for people to contact and tasks that are overdue or due today. It shows whichever board sections you have enabled.

People

Everyone you keep track of. Press Add… for a simple form, or type Name | Client | Role and press Enter for a quick add.

Pipeline

People by stage. Drag a card to change the stage. Logging a sent message moves a new person to the second stage.

Messages and calls

In a person's card, write what you sent or said, pick the channel, then Log. Tick Draft to keep a message you have not sent yet. Mark sent when you send it.

Client files

Keep big files in Google Drive, Dropbox or OneDrive. Add the folder links in the Files part of a person's card.

Tasks

Board, List, Calendar and Schedule show the same tasks. Double-click a card to open it. A task can be linked to a person.

Search and archive

Press / or click to search everything. Old done tasks and Lost people can be moved to the archive (Settings → General). Search finds them, and you can put them back.

Undo and safe removal

Tap Undo in the message that appears after each change, or use Ctrl+Z on Windows/Linux, or ⌘Z on a Mac to reverse recent saved board changes. Keeptrack asks before deleting people, tasks, contact details and other important items.

Read-only

The demo board, a public board with no token, and a token without write access are read-only. A banner at the top tells you why.

    @claude on the boardType @claude in a task comment, and your own Claude routine starts work on that task.

    1. A routine is Claude working in the cloud for you. It uses your own Claude plan.

      Open Claude routines →

      Click New routine and fill in:

      Name
      Instructions
      Repository
      • Environment: add a new one with the same name. Keep network access at Trusted.
      • Connectors: remove all of them.
      • Model: Sonnet is enough.

    2. The routine needs its own GitHub token for this board.

      Open GitHub: make a token →
      1. Repository access: select Only select repositories, then .
      2. Check that Contents is Read and write (the link sets it). Click Generate token and copy it.
      3. In your routine, open the environment. Add an environment variable with this name, then paste the token as its value:
      NameBOARD_TOKEN

      This token stays in your routine. This page never sees it.

      1. In your routine, click Edit, then Add another trigger, then API. Save.
      2. Copy the trigger's URL and paste it below.
      3. Click Generate token. Copy it at once, because it shows only one time. Paste it below.

    4. A web page cannot start a routine by itself. A free cron-job.org account does it for the page, in about one minute.

      Open cron-job.org →
      1. Sign up (free) or sign in.
      2. Go to Settings → API, enable it and click Create API key.
      3. Copy the key and paste it below.
      What does cron-job.org see?Your routine's trigger token and the task number, never the task's text. The page deletes the job as soon as it has run.

    5. The page makes a small test task and asks Claude to say hello on it. This takes about two minutes.
