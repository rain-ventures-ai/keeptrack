# Client files

Keep large files (PDFs, slide decks, contracts, spreadsheets) in your normal file store, not in GitHub. Keeptrack keeps **links** to them.

## Link a company's folders
1. Open a person who works at the company.
2. In **🗂 Files for <company>**, paste a link and press Enter. To give it a name, type `Name | link`, for example:
   ```
   Proposal folder | https://drive.google.com/drive/folders/...
   ```
3. Add as many links as you need: Google Drive, Dropbox, OneDrive, SharePoint, Notion or any other web link.

The links belong to the **company**, so each person at that company shows the same files.

## Why not GitHub?
- GitHub refuses files over 100 MB.
- Git keeps each old version for ever, so the repo becomes large.
- People without GitHub cannot open or edit the files.

## Can my AI assistant read the files?
Yes, if your assistant has a connector for that store (for example the Google Drive or Dropbox connector in Claude). Ask it: "Read the latest proposal in the Acme files folder."

## A person's own links
**🔗 Links** on a person's card is for links about that person only, for example a profile or a meeting recording.
